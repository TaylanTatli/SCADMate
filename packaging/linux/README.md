# SCADmate Linux binary

Run the application directly:

```sh
./scadmate
```

This archive uses the host's Linux libraries. Install WebKitGTK 4.1 and GTK 3 through your
distribution's package manager. On Arch Linux, the primary runtime packages are
`webkit2gtk-4.1` and `gtk3`.

The included desktop file and icon are provided for package maintainers. A system package can
install them under `/usr/share/applications` and `/usr/share/icons/hicolor/128x128/apps`.
